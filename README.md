# 🌌 LibreOS 1.0 — "La tecnología me está abriendo puertas, yo les daré caminos libres."

¡Bienvenido a la base de operaciones oficial de **LibreOS**! Este es un sistema operativo independiente enfocado en la ciberseguridad, la privacidad del usuario y la optimización extrema. Diseñado para ofrecer una experiencia fluida a puros 60 FPS estables sin necesidad de componentes caros.

El software está construido con el respeto a las licencias open source, tomando como cimiento la tecnología de **Pop!_OS (System76)** y el **Kernel de Linux de Linus Torvalds**.

---

## 🎨 El Motor Gráfico: Minium Cloud

LibreOS implementa el entorno visual **Minium Cloud**, un concepto que fusiona:
*   **Minimalismo COSMIC**: Interfaces limpias, eficientes y libres de basura informática o telemetría que te espía.
*   **Aesthetic Glow**: Degradados y efectos de iluminación neón en tonalidades moradas y lilas.
*   **Aero-Glass**: Ventanas translúcidas con desenfoque profundo (*blur*) optimizadas para no saturar tu memoria RAM.

## 📘 Manual de Usuario: Cómo Probar las Betas en Scratch

Sigue atentamente esta guía paso a paso desde el absoluto cero para ejecutar el entorno en tu monitor:

### 🏁 Paso 1: Abrir el Navegador y entrar a GitHub
1. Abre tu navegador **Google Chrome**.
2. Entra a [github.com](https://github.com).
3. *(Opcional)* Si tienes cuenta, haz clic en **Sign In** e inicia sesión para guardar el proyecto en tus favoritos. Puedes continuar como invitado si no tienes una cuenta.

### 🔍 Paso 2: Buscar al Desarrollador
1. Ve a la barra de búsqueda superior de GitHub.
2. Escribe exactamente: `programador1002` y presiona **Enter**.
3. Filtra los resultados seleccionando la pestaña **"Users"** (Usuarios).
4. Haz clic en el perfil oficial de **Matias** (`programador1002`).

### 📂 Paso 3: Entrar al Repositorio y a la Web
1. En el perfil, haz clic en la pestaña **"Repositories"** (Repositorios).
2. Abre el proyecto llamado **`LibreOS`**.
3. En la descripción del repositorio, haz clic en el enlace del despliegue: [programador1002.github.io/LibreOS](https://github.io). Se abrirá el sitio web del sistema.

### 📱 Nota Especial para Celulares
* Si estás navegando desde un teléfono móvil, toca el botón de los **tres puntos** en la esquina superior derecha de tu navegador Chrome.
* Marca la casilla **"Sitio para computadoras"** (o "Vista de escritorio") para que la interfaz se adapte perfectamente a tu pantalla.

### 🚀 Paso 4: Desplegar el Código
1. En la página web de LibreOS, desliza hacia abajo hasta ver el **botón amarillo** que dice **"Betas en Scratch"**.
2. Al presionarlo, volverás automáticamente a GitHub.
3. En la esquina superior izquierda de la pantalla de GitHub, haz clic en el menú que dice **"main"** o **"2 branches"** y cambia a la rama llamada **`sb3`**.

### 🛠️ Paso 5: Ejecutar o Editar
*   **Para editar en Scratch**: Descarga el archivo maestro llamado `LibreOS-KernelBASE.sb3` a tu computadora y cárgalo en la aplicación de Scratch para modificar el código.
*   **Para correr en la Web de inmediato**: Busca el enlace fijo de la página `programador1002.github.io/LibreOS-0.1`. Se abrirá el emulador en pantalla completa. ¡Haz clic en la **banderita verde** y el sistema arrancará!

*Nota: Se recomienda el uso de **PC** de torre para disfrutar de los gráficos fluidos sin lag.*
